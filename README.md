## About This Repository
This repository contains frequently used C programming examples and basic algorithms. It is created using Git and GitHub to understand version control, code management and collaboration.

## List of Programs

1. **Bubble Sort:** Sorts array elements in ascending order.
2. **Linear Search:** Searches for an element in an array.
3. **Factorial Using Recursion:** Calculates factorial using a recursive function.
4. **File I/O:** Demonstrates writing data into a file using C.
5. **Matrix Multiplication:** Multiplies two 2×2 matrices.

## Compilation and Execution

Use GCC compiler to compile and execute the programs.

Example:

```bash
gcc bubble_sort.c -o bubble_sort
./bubble_sort
```

Similarly, compile and execute other programs:

```bash
gcc linear_search.c -o linear_search
./linear_search

gcc factorial_recursion.c -o factorial
./factorial

gcc file_io.c -o file_io
./file_io

gcc matrix_multiplication.c -o matrix
./matrix
```
